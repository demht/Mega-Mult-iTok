# Mega MultiTok V4

Telegram-бот на Python для запуска через Visual Studio Code.

## Что изменено

- Кнопки TikTok, YouTube и Instagram в стартовом меню больше не открывают сайты.
- При нажатии кнопка только подсказывает отправить ссылку в чат.
- К скачанному видео добавлена подпись «Всё готово».
- Добавлена админ-панель по команде `/admin`.
- В админ-панели есть статистика пользователей и рассылка.
- Рассылка поддерживает текст, фото, видео, документы и подписи.
- Пользователи сохраняются в локальной базе `mega_multitok.db` после запуска бота.

## Настройка

1. Открой папку проекта в Visual Studio Code.
2. Создай окружение:

```powershell
python -m venv .venv
```

3. Выбери `.venv` через `Python: Select Interpreter`.
4. Установи библиотеки:

```powershell
python -m pip install -r requirements.txt
```

5. Открой `.env` и вставь токен и свой цифровой Telegram ID:

```env
BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
ADMIN_ID=ТВОЙ_ЦИФРОВОЙ_ID
```

Цифровой ID можно узнать у Telegram-бота `@userinfobot` или аналогичного бота.

6. Запусти `main.py`.

## Админ-панель

Отправь своему боту команду:

```text
/admin
```

Нажми «Новая рассылка», отправь рекламный пост и подтверди отправку. Рассылка уйдёт только пользователям, которые уже запускали бота.

## Важно

Обычный Telegram Bot API принимает файлы примерно до 50 МБ. Бот пробует уменьшать качество длинных роликов, но очень большие видео могут не поместиться.
